# Universal Toggle Click Fix (Laptop Compact Edition)
Desarrollado por ©J.E Studios & ©Esmeiden Corp

## De qué trata esta herramienta
Este software es una utilidad externa y universal pensada para solucionar un problema muy molesto cuando se juega o se trabaja en laptops: la falta de comodidad al usar el touchpad o teclados compactos. 

Lo que hace el programa es simular hardware real para crear un interruptor (Toggle) en el Clic Derecho del mouse. Con solo presionar una vez la tecla ALT Izquierdo, la mira o la acción se queda clavada, y al volver a presionarla se suelta. Al ser un script de uso general, sirve para lo que quieras: desde apuntar fijo en shooters como Metal Gear Solid V sin cansarte los dedos, hasta mantener el clic presionado para arrastrar archivos pesados entre carpetas o diseñar más cómodo.

## Detalles técnicos
* Peso mínimo: Está compilado en un ejecutable (.exe) de solo 1.24 MB que consume prácticamente 0% de RAM y procesador.
* Respuesta real: Incluye un retraso de 30 milisegundos para imitar la velocidad de un dedo humano, evitando que el sistema o el juego ignoren el comando por ir demasiado rápido.
* Permisos avanzados: Se ejecuta automáticamente con privilegios de Administrador para asegurar que los videojuegos exigentes lean la tecla sin problemas.
* Diseño limpio: Cuenta con una ventana simple en modo oscuro y emite un pitido (Beep) al encenderse y apagarse para que sepas cuándo está activo.

## Advertencias y Notas de Soporte (Leer antes de usar)
* Sin pruebas formales: Esta herramienta fue desarrollada de forma independiente y artesanal. No se ha probado formalmente en un entorno masivo de diferentes sistemas operativos o hardware. Úsala bajo tu propio criterio.
* Falsos positivos: Al pedir permisos de administrador para mover las teclas virtuales de Windows, es muy probable que SmartScreen o tu antivirus te digan que el "Autor es desconocido". El programa es transparente y el código está abierto en este mismo sitio para que cualquiera pueda revisarlo con el bloc de notas.
* En caso de fallas: El programa es totalmente independiente y funciona directo con el .exe. De todas formas, si experimentas tirones, bloqueos de teclas o algún error raro en tu Windows, se recomienda descargar e instalar oficialmente AutoHotkey v2.0 o superior en tu computadora para asegurar que las librerías nativas de Windows lean bien el script.
